# Project governance

Starfire Engine currently follows a maintainer-led governance model.

- Maintainers decide roadmap priorities and whether changes enter releases.
- Pull requests require review before merge.
- Breaking APIs are expected during `0.x` development and will be documented.
- Community suggestions are welcome through discussions and issues.
- The Apache-2.0 license applies to source code in this repository; it does not grant trademark rights to the Starfire Engine name or logos.

Future governance changes will be proposed publicly before adoption.
