Technical limits: one fixed ortho directional shadow volume; 3x3 PCF; simple
procedural sky/horizon/ground reflection approximation, not true image-based HDR
IBL or cubemap reflection probes; no cascades, point/spot shadows, contact-hardening,
normal maps, transparent shadow casting or alpha-tested materials.

This package passed 84/84 Node unit/integration tests in the packaging environment.
Both GLSL shader pairs compiled/linked in EGL/OpenGL ES 3 software renderer;
depth shadow framebuffer completeness also validated there. The local Chromium
browser was blocked from loading the local server, so browser WebGPU testing must
be done on a supported GPU/browser (e.g., RX 6600).
