## SDK and packaging gate

- [ ] `npm run release:check` passes on Node 20 and 22.
- [ ] `npm pack --dry-run --json` includes source, metadata, README and license/notice; excludes tests and internal workspace artifacts.
- [ ] New clone from the candidate tag can run `npm run dev` with only Node installed.
- [ ] `GLTFLoader` loads the public Starfire Relay GLB, with no scene-ownership error.
- [ ] Source archive contains no unrelated private application code/assets/configurations.
- [ ] GitHub tag is immutable once published; `main` and release metadata match.
- [ ] Final release notes acknowledge unsupported features and observed browser results.

## Release blocking criteria

**Block the final tag** if there is a reproducible startup failure in any claimed supported browser/backend, black/invalid rendering, corrupted import data, GPU memory that grows without bound on repeat operations, a security file-exposure regression, or an undocumented feature mismatch.

When a browser is unsupported, **document that limitation** rather than incorrectly marking it passed. Open a tracked issue for non-blocking defects, and include it in the release notes.
