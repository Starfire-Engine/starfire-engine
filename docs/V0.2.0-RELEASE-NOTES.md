# Starfire Engine v0.2.0 — Rendering & Asset Foundation

**Public open-source release · Apache 2.0**

Starfire Engine takes its first major step beyond the original 3D rendering prototype. Version 0.2 introduces textured and PBR materials, static GLB/glTF imports, directional shadows, an original model showcase, GPU instancing and performance diagnostics—all with Starfire's independent WebGPU and WebGL 2 rendering backends.

## Highlights

- **Import compatible 3D models:** load static glTF 2.0 / binary GLB scenes with nested nodes, triangle meshes, multiple primitives and supported PBR materials.
- **Render richer materials:** image textures, metallic and roughness parameters, direct-light GGX shading, exposure and tone mapping.
- **Build more complete scenes:** transform hierarchies, quaternion support, geometry attributes, 32-bit indices and resource caching.
- **Improve lighting:** optional directional depth-map shadows with soft PCF filtering and approximate procedural environment lighting.
- **Optimize rendering:** camera/shadow frustum culling, explicit instanced meshes and CPU performance/resource diagnostics.
- **Try the demo:** public Starfire Relay GLB model, material spheres, shadow controls, optional 256-instance stress test and benchmark readout.
- **Fix reliability issues:** correct WebGPU shader initialization, depth texture setup, local development file serving and imported scene ownership handling.

## Getting started

```bash
git clone https://github.com/Starfire-Engine/starfire-engine.git
cd starfire-engine
npm run dev
```

Open `http://localhost:5173/`, or explicitly select `?renderer=webgpu` / `?renderer=webgl2`. Requires Node.js 20+ for the local tools and a browser supporting WebGPU or WebGL 2.

## Known limitations

This is a **pre-1.0 graphics/asset engine**, not a complete game editor or runtime. Animation, physics, audio, scripting and visual authoring tools are future work. The importer supports a defined static glTF subset; skins, compressed extensions, alpha blending and normal maps are not supported. Shadows are single-directional; procedural environment lighting is not HDR IBL. GPU timing is not yet measured; GPU memory values are estimates.
