# Security policy

## Supported versions

This repository is in pre-alpha. Security fixes target the latest pre-alpha only.

## Reporting vulnerabilities

**Do not disclose exploitable vulnerabilities in a public issue.** Use GitHub's **Report a vulnerability** / private vulnerability reporting feature if enabled, or contact the maintainers privately through their published security contact.

Please include reproduction steps, affected components, impact, and a possible patch if available. Avoid publishing proof-of-concept exploits before coordinated disclosure.
