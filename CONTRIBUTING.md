# Contributing to Starfire Engine

Thanks for helping build a reusable, open-source web engine!

1. Open an issue before attempting large architectural changes.
2. Fork the repository and create a topic branch.
3. Keep features general-purpose; do **not** submit proprietary, application-specific source, assets, or operational logic.
4. Run `npm run ci` before opening a pull request.
5. Include focused tests and documentation for new public APIs.
6. Describe browser compatibility and performance consequences for rendering changes.

By contributing, you certify that you have the right to submit the material under Apache-2.0. Include a `Signed-off-by: Your Name <you@example.com>` line in commits to signify the [Developer Certificate of Origin](https://developercertificate.org/); you can use `git commit -s`.

The engine should remain usable without proprietary accounts or external services.
